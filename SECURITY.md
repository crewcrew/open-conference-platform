# Security

Do not post credentials, attendee information or detailed vulnerability exploits in public issues.

Use GitHub's private vulnerability reporting in the repository's Security tab if available. Otherwise contact the maintainer through their GitHub profile to arrange a private report before sharing sensitive details. No response-time commitment or formal support policy is currently offered.

Production installations are operated by the people self-hosting the software. Keep dependencies updated, use HTTPS and PostgreSQL, protect secrets, back up the database and verify access controls and payment integrations before accepting real registrations. See docs/production.md for deployment requirements and known operational limits.

The Lovable demo uses sample data and does not handle live registrations or payments.
